What changes on the Case list, and why

  1. 1Text filter beside “Open Case”, live-update pill instead of “Refreshes live”.Finding a known Case today means leaving for global search. The pill says what changed rather than reshuffling rows under the cursor.Now: list.tsx header has only “Refreshes live” text and the button.
  2. 2One-line filter chips with multi-select, Assignee, Tag and “Clear filters”; a Sort control.Filters take a whole card of full-width selects, allow one value each and can't be reset in one click; the order can't be changed.Now: three NativeSelects in a Card; fixed sort.
  3. 3Severity stripe and title-first rows; the whole row is one link.Every row has two separate links (C-number and title). Case Type and Restricted move under the title to free columns.Now: Case / Title / … / Case Type columns, two links per row.
  4. 4Tasks progress with overdue count.Overdue Tasks are invisible until the Case is opened. Needs done/total/overdue on the list endpoint (only the single-Case view carries Task counts today).
  5. 5Last activity says what happened and who.“2 h ago” alone doesn't tell an Analyst whether to look. Closed also gets a count like the other views.
  6. 6“Assign to me” on unassigned rows, and how long a New Case has waited.Picking up work takes three steps today (open, find the select, pick yourself).
