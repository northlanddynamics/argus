What changes on Tasks, Evidence and the Audit Log, and why

  1. 1Open / Done split, “Only mine”, sort by due date.Done Tasks stay interleaved with open ones in creation order, so the list gets harder to scan as a Case matures.Now: tasks.tsx renders every Task in one table, no filter or sort.
  2. 2Inline quick-add row.Most Tasks are a title, an owner and maybe a date; the dialog stays for descriptions and edits, opened by clicking the row instead of a per-row Edit button.
  3. 3Ticking a Task shows Undo and only that row waits.Today one pending tick disables every checkbox in the table.Now: disabled={readOnly || setDone.isPending} on all rows.
  4. 4Upload moves to a header button; the whole card is the drop target.The dashed drop zone takes a permanent band above the files.
  5. 5Icon actions; the column header says opening is logged.Copy + View + Download are three outline buttons per row. Files that can't be previewed don't offer View.
  6. 6Uploads in progress and failures show as rows in the table, with Cancel and Retry.Today they stack as separate alerts and progress bars above the table, and a failure can only be dismissed.
  7. 7Audit Log filters as chips with multi-select actions, a date range, and CSV export.Today: one action at a time and a “From” date with no end.
  8. 8Grouped by day; Promote in a row menu.A “Promote to Timeline” button on every row is the loudest thing in the log. Long logs page; today the API stops at 1,000 entries without saying so.
