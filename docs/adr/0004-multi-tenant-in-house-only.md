# Multi-tenant SaaS for in-house teams only; no MSSP model

Argus is one hosted service serving many independent in-house security teams, each an Organization isolated from the others. It will never model MSSPs or IR firms working Cases on behalf of multiple client companies: there is no Client layer beneath the Organization. Outside parties (counsel, insurers, external IR firms) participate only as Guests on specific Cases. This keeps permissions and data isolation one level deep; supporting MSSPs would require a different product, not an extension of this one.
